# 📰 Bangla News 24

Bangla News 24 is a responsive Bangla news web application that helps users explore the latest news, browse different categories, and stay updated with current events through a clean and user-friendly interface.

## 🌐 Live Website

[Visit Bangla News 24](https://bangla-news-24-henna.vercel.app/)

## 🛠️ Technologies Used

- Next.js
- React.js
- TypeScript
- Tailwind CSS

## ✨ Key Features

- **Latest News:** Explore the latest news and updates.
- **Category-Based News:** Browse news by categories such as Politics, World, Economy, Health, Sports, and Technology.
- **Featured News:** Discover selected and important news articles.
- **Breaking News:** Stay updated with the latest headlines.
- **Most Read News:** Explore popular and trending articles.
- **News Sections:** Browse news from different sections, including Bangladesh, India, World, and more.
- **Responsive Design:** Enjoy a smooth browsing experience across desktop, tablet, and mobile devices.
- **Authentication UI:** Includes sign-in and sign-up navigation.

## 🚀 Getting Started

Follow these steps to run the project locally.

### 1. Clone the Repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the Project Folder

```bash
cd bangla-news-24
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Run the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

## 🎯 Project Purpose

This project was built to practice Next.js development, TypeScript, component-based architecture, responsive web design, and building a modern news platform.
